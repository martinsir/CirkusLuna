# CirkusLuna

CirkusLuna was a semester project developed as part of the Computer Science programme.

The project was a booking system for a travelling circus where users could select a city and book different types of seats, including normal and VIP seating.

The purpose of the project was to combine several of the programming concepts we had learned during the semester into one larger application.

## About the project

The application was designed around managing circus events and seat bookings.

The project included work with:

- Booking functionality
- Normal and VIP seats
- City selection
- Object-oriented programming
- Classes and objects
- Inheritance
- Collections and data handling
- JSON data storage
- Validation
- Application structure
- Git and version control

## Technologies

The project was developed using:

- C#
- .NET
- JSON
- Visual Studio
- Git
- GitHub

## What I learned

The project gave me practical experience with:

- Designing a larger application from requirements
- Structuring classes and responsibilities
- Working with inheritance and object-oriented design
- Managing collections of objects
- Implementing booking logic
- Reading and writing data using JSON
- Validating user input
- Connecting multiple parts of an application together
- Planning and developing a project over a longer period
- Working with Git during development

## Project context

CirkusLuna was a semester project where the goal was to apply the different programming concepts learned throughout the semester in a more complete application.

It was primarily a learning project and not intended as a production-ready booking system.
